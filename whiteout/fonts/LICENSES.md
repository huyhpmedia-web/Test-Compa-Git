Be Vietnam Pro was designed for Vietnamese: stacked diacritics (ệ ở ữ ẫ) have proper vertical metrics.
It is the project default font (`gui/theme/custom_font`, also used by in-world `Label3D` signs) and the UI
theme font (`ui/ui.gd:_make_theme`), with a system font only as a symbol fallback.
