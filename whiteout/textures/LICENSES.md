# Texture sources and licences

All files in this folder are either **CC0 1.0** (public domain dedication) PBR sets from ambientCG / Poly Haven, or **procedural** textures generated by `tools/gen_textures.py` (our own work, CC0).

CC0 needs no attribution, but credit is given anyway. ambientCG assets are created by Lennart Demes and the ambientCG contributors. Poly Haven assets are created by the Poly Haven artists (e.g. Rob Tuytel, Dimitrios Savva, Rico Cilliers and others; the exact artist is shown on each asset page).

## How the real textures were obtained

polyhaven.com / ambientcg.com are unreachable from the build environment, so the original CC0 maps were taken from the public CC0 data mirror **MorePET/mat-vis** (https://github.com/MorePET/mat-vis, release `v2026.04.0`, files `mat-vis-<source>-<tier>-<category>.parquet`), which re-hosts the unmodified ambientCG and Poly Haven PNG maps (1k and 512 tiers) and states their licence as CC0-1.0.

Modifications (done by `tools/gen_textures.py --src`): normal maps converted DirectX to OpenGL (green channel inverted); non-square sets tiled to a square (keeps real-world aspect); albedo re-graded (brightness / saturation / hue / tint) to the intended look of the preset; roughness remapped (multiply + offset). Geometry detail is untouched and all sets remain seamless.

## Gore decals (`textures/gore/`)

No suitable CC0 blood/gore decal set is reachable from the build environment (polyhaven.com and
ambientcg.com are blocked, and the MorePET/mat-vis mirror only re-hosts tiling surface materials, not
decals), so **every file in `textures/gore/` is procedural**: generated by `tools/gen_gore.py` (numpy +
PIL, seeded, deterministic; our own work, released CC0).

Per decal `<name>` there are `<name>_a.png` (albedo RGBA), `_n.png` (normal), `_o.png` (ORM: occlusion /
roughness / metal) and, for the Rimebound-fluid variants, `<name>_i.png` (ichor albedo). Mipmaps are on.
Sets: `splat_a-d`, `splat_wall`, `spray_a/b`, `pool_a-c`, `smear_a/b`, `drag_a/b`, `hand_r/l/smear`,
`foot_r/l/bare`, `drips_a/b`, `puddle_a/b`, `ripple`, `outline` (chalk body outline), `write_help/run/sleep/out`
(blood-written wall messages, rendered from FreeSans Bold, GNU FreeFont, then warped + shaded) and
`screen_blood_a/n` (full-screen lens overlay used by `ui/blood_screen.gd`).
