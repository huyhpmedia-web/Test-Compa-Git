# Vietnamese glossary and style guide (`locale/vi.po`)

English is the source language (msgid == the exact English string in code). `locale/strings.pot` is
generated by `tools/extract_strings.py`; `locale/vi.po` is the hand-written Vietnamese translation.

Workflow: edit/add English strings in code -> `python3 tools/extract_strings.py --sync` (adds new msgids
with an empty msgstr, drops stale ones) -> translate -> `python3 tools/extract_strings.py --check`
(coverage, placeholder and BBCode mismatches) -> `godot --headless --script res://tools/loc_check.gd`
(engine-side check). Printf placeholders (`%s %d`) must stay in the same order as in English.
`[b]`, `[i]`, `[center]`, `[color=...]` tags must be preserved.

## Voice

* Tone: restrained, literary, cold; short sentences stay short. Horror by understatement.
* Narration/POV is Elias (a Minnesota lineman, ~40): item descriptions and toasts use no subject
  pronoun where possible ("Quẹt cháy một quả pháo sáng."), never the generic gamey "bạn" unless a
  document is addressed to a stranger ("Nếu bạn đang đọc dòng này...").
* Family terms (family drama is the heart of the story):
  * June <-> Elias: June says **bố** / **con**; Elias says **bố** / **con** / **nhóc** ("kiddo").
  * Elias <-> Ruth (his mother): **mẹ** / **con**. June calls Ruth **bà** ("Gran"), Tom **ông** ("Grandpa").
  * Tom -> Ruth (letter): **anh** / **em**. Tom -> Elias: **bố** / **con**; Elias addresses his dead father **bố**.
  * Strangers/colleagues: tôi / anh / chị / ông / bà; Dr. Hart is **Tiến sĩ Hart** ("tôi" - "anh").
  * MERIDIAN (the data-centre AI) is always polite and bureaucratic: **quý vị**, "Xin hãy...".
* Diacritics: use standard (new-style) tone mark placement (hoà -> hòa, thuỷ -> thủy).
* Numbers: Vietnamese separators (1.204 ; 146,52 MHz ; 99,9997%). Dates: `21 tháng 12, 2026`, short `19/12`.
* Keep proper nouns untranslated: Elias, June, Ruth, Tom, Kettle Falls, Lower Kettle, Corvane Systems,
  Northline Mineral, Lakeshore Electric, MERIDIAN, St. Brendan, Minnesota, Highway names with number.

## Fonts

All UI text uses **Be Vietnam Pro** (SIL OFL 1.1, `fonts/OFL.txt`), designed for Vietnamese stacked
diacritics; the system font is only a glyph fallback for symbols. `gui/theme/custom_font` also covers
in-world Label3D signs.
