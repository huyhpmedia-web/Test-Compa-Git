# Enemy / boss assets - sources and licenses

`choir.glb`, `hauler.glb`, `mother_p1.glb`, `mother_p2.glb`, `hound.glb` are produced by the scripts in
`tools/charpipe/bosses/` (Blender 5.0 as a Python module: `pip install bpy`; see `tools/charpipe/README.txt` for the venv).

| Data | Source | License |
|---|---|---|
| Human bodies, clothes, hair of the Choir congregants, the Hauler's miners / driver and Ruth (Hollow Mother) | The project's own MakeHuman-based character glbs `assets/characters/{rimebound_civ_m,rimebound_civ_f,rimebound_miner,rimebound_nurse,ruth,elias,june}.glb` (CC0 MakeHuman base mesh, targets, clothes, hair and eyes - see `assets/characters/LICENSES.md`), re-posed, deformed (stretched skulls, torn-open mouths, torn chests), decimated and re-textured by `bosses/bosslib.py` | CC0 1.0 |
| Dead-skin / frozen-cloth / flesh textures | Generated procedurally from the character textures and noise (`bosses/texgen.py`) | CC0 (project original) |
| Rime hound mesh, rig, fur texture | Modelled from scratch (Skin-modifier tubes + subdivision + displacement) in `bosses/build_hound.py`; no third-party mesh | CC0 (project original) |
| Ice crystals, lattice, mortar of fused flesh, tyre, rocks, cab, bones, tendrils | Procedural geometry in `bosses/common.py` / `build_*.py` | CC0 (project original) |
| Blender (bpy) | https://pypi.org/project/bpy/ (5.0.1) | GPL-3.0-or-later (tool only; no Blender code is shipped) |

No downloaded third-party creature models are used. The `.glb.import` / extracted texture files next to the glbs are
generated by Godot's importer.

Rebuild (from `tools/charpipe`): `BOSS_SRC_GLB=<dir with the character glbs> venv/bin/python bosses/build_choir.py` (likewise
`build_hauler.py`, `build_mother.py`, `build_hound.py`); outputs go to `assets/enemies/` (override with `BOSS_OUT`).
